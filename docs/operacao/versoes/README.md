# Acervo de versões e baselines da documentação de governança

Este diretório preserva cópias integrais e imutáveis (byte a byte) das versões ou baselines anteriores dos documentos normativos de governança do projeto **Escala do Reino**, arquivadas antes da aplicação de mudanças normativas relevantes autorizadas pelo responsável pelo produto.

O procedimento principal está no [fluxo multiagente, seção 5.5](../FLUXO-MULTIAGENTE.md#55-evolução-e-preservação-de-documentos-normativos). A numeração `1.1` foi adotada formalmente nesta evolução para os três documentos que antes não declaravam número; não pressupõe uma versão `1.0` anterior para eles. O modelo reutilizável já declarava a versão `1.0`.

## Regras de vigência e preservação

- **Entrada vigente obrigatória:** [`AGENTS.md`](../../../AGENTS.md), na raiz do repositório, permanece como a única entrada normativa vigente de governança, acompanhado das versões atuais de [`docs/operacao/FLUXO-MULTIAGENTE.md`](../FLUXO-MULTIAGENTE.md) e [`docs/operacao/GUIA-TRABALHO-GITHUB.md`](../GUIA-TRABALHO-GITHUB.md). O [`modelo reutilizável`](../../modelos/governanca/MODELO-GOVERNANCA-IA-REPOSITORIOS.md) é uma base de adaptação para outros repositórios, sem substituir as regras locais ou conceder autorização.
- **Sem efeito autorizativo de cópias históricas:** nenhum arquivo arquivado nesta pasta concede autorização operacional, reabre gates aprovados ou substitui automaticamente as regras vigentes.
- **Imutabilidade dos bytes preservados:** cópias históricas nunca devem ser sobrescritas, reformatadas ou editadas após o arquivamento. Correções ou novas evoluções normativas geram um novo arquivo datado quando exigido pela política de versionamento.
- **Como consultar links relativos nas cópias preservadas:** como os arquivos desta pasta conservam exatamente os bytes originais, os links Markdown relativos em seu interior permanecem calculados a partir do **caminho de origem de cada documento** (por exemplo, a raiz `/` para `AGENTS.md`, `docs/operacao/` para `FLUXO-MULTIAGENTE.md` e `GUIA-TRABALHO-GITHUB.md`, e `docs/modelos/governanca/` para `MODELO-GOVERNANCA-IA-REPOSITORIOS.md`), e não a partir de `docs/operacao/versoes/`. Para navegar por esses links, interprete os caminhos relativos a partir do diretório listado na coluna **Origem** da tabela abaixo ou consulte o documento vigente correspondente.
